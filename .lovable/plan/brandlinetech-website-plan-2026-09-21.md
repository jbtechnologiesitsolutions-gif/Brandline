# BrandlineTech Website Plan

## Scope
Build a complete premium multi-page website for BrandlineTech with these routes:

- `/` — full homepage and conversion journey
- `/services`
- `/solutions`
- `/marketplace-management`
- `/packages`
- `/about`
- `/contact`
- `/privacy-policy`
- `/terms`

## Design system
- Establish the supplied charcoal, ivory, white, warm-gold palette as semantic design tokens.
- Use Manrope for headings and Inter for body text.
- Apply restrained borders, shadows, editorial spacing, and subtle motion.
- Keep the visual direction monochrome and premium, avoiding stock imagery, glass effects, and excessive gradients.
- Build an original dashboard-style commerce visual with charts, orders, products, channels, and marketplace indicators.

## Shared experience
- Create a sticky desktop navigation and accessible mobile drawer.
- Add a shared footer, consultation CTAs, platform strip, and reusable content components.
- Use structured data arrays for services, packages, FAQs, industries, process steps, and marketplace capabilities.
- Ensure every navigation item and CTA reaches a real page or relevant section.

## Homepage
Implement the complete requested flow:

1. Hero with animated digital growth dashboard
2. Platform expertise strip
3. Growth-partner introduction
4. Three major service groups
5. Attract / Convert / Sell / Retain / Scale framework
6. Five-step process timeline
7. Marketplace management feature and service grid
8. Marketplace packages, comparison, and add-ons
9. Digital marketing dashboard section
10. Web and technology capabilities
11. Why BrandlineTech
12. Industries served
13. About and operating model
14. Editable placeholder metrics
15. Value statements instead of invented testimonials
16. Accessible FAQ accordion
17. Final consultation CTA
18. Contact information and validated consultation form

## Supporting pages
- Reuse the same content system while giving each page a focused hierarchy and page-specific content.
- Make marketplace management and packages especially detailed.
- Include the supplied contact information exactly.
- Provide clear privacy and terms pages without inventing legal/business claims.

## Interaction and accessibility
- Add reduced-motion-aware entrance and hover transitions.
- Animate dashboard charts, staged cards, counters, and timeline progress subtly.
- Implement keyboard-accessible navigation, drawer, accordions, forms, and visible focus states.
- Add click-to-call and click-to-email actions.
- Validate required form fields and show a local success/ready-to-submit state without claiming an email was sent.

## Responsive behavior
- Desktop layouts use a broad 1200–1400px content frame.
- Tablet layouts adapt to two columns.
- Mobile uses purpose-built stacked layouts, a sticky header, horizontal platform scrolling, stacked pricing, and a scrollable comparison table.
- Verify at desktop and mobile sizes for overflow, overlap, readability, and working interactions.

## Metadata and verification
- Add unique route metadata with the requested homepage title and description, Open Graph fields, canonical paths, and social card settings.
- Preserve semantic heading order and page landmarks.
- Check the project build status after implementation and verify the rendered homepage and key interactions in the browser.
